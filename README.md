# LUMA RITUAL — modern wow landing page

Ready-made static landing page inspired by colorful wellness/e-commerce aesthetics.

## How to run

1. Unpack the archive.
2. Open `index.html` in your browser.

## Structure

- `index.html` — page markup
- `css/style.css` — all design, responsive styles and animations
- `js/main.js` — interactivity: reveal animations, tilt cards, ritual switcher, canvas particles

## Features

- No build tools or frameworks
- Responsive and mobile-first
- Original CSS illustrations without copying external images
- Smooth animations, glassmorphism, gradients, running ticker, interactive cards
